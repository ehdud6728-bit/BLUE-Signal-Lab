# 키움 굵은 파란색 점선 30·2·26 집중 검증 (연구 전용)

## 사용자 확정 사항
- 실제 차트의 연구 대상: **굵은 파란색 점선**. 설정: 볼린저밴드 **30, 2, 26**.
- 이전 40일선 모델의 캐스텍코리아/에스엘 손절, 아진산업/하이브 익절 예시는 **30일선 매매 사례가 아님**. 같은 종목·날짜가 30일 모델에서 따로 신호인지 새로 검사.
- 20/40 비교 코호트는 보존하되 30일 결과를 연구 보고서의 첫 번째 섹션으로 출력.

## 누락된 검증
- 30·2·26 설정을 알고 있어도 화면의 파란선이 **BBandsUp/BBandsDown**, Close/HLC3 어느 가격 소스인지 4종목의 선에 선택일 실제 숫자가 제공되지 않았다.
- 과거 스페코 2026-10-21/22/23의 30일 HLC3 하단 모델값 1,529.135/1,531.152/1,533.748이 키움 유저제공 1,529.14/1,531.15/1,533.75와 근접하다는 사실은 **단일 종목 3일의 수치**로만 사용한다. 실제 4종목에 일반화할 수 없다.
- 4종목 스크린샷의 OHLC와 비수정 MARCAP 일봉 OHLC가 차이 나는지 수치와 함께 보고, 차이가 있으면 모델 결과를 실제 키움 거래와 동일시하지 않는다.

## 연구 코드
- `scripts/blue_dot_30_2_26_parity_audit.py`: 4개 사용자 스크린샷의 KRX 종목코드·날짜·OHLC에 대해 30일 HLC3 하단/Close 하단/HLC3 상단/Close 상단 네 가설별 해당일 선값, 3회·5회 하락, 양봉 아래→위 돌파, 차트 OHLC 차이, 후속 첫 익절·손절 **모델만** 재판정.
- 기존 `report.json`, `slope_report.json`, `breakout_context_report.json` 30일 3회/5회 코호트의 총 건수/첫 익절/첫 손절/갭/미해결이 맞는지 확인. 30일 기존 연구의 최근 모델상 익절·손절 종목 3개씩 별도 제시.
- 키움 **굵은 파란 점선의 선택일 실제 값이 없으면 `broker_line_numeric_parity_status=UNVERIFIED_NO_SELECTED_DAY_BLUE_LINE_PRICE`를 유지**하고 브로커 인증 신호 건수 0건.
- 기존 사용자 모델 TP+2.5%/SL−4.5%/최대 5거래일 최초 접촉 및 시장 달력·SHA 고정 수집 유지. 새로운 30/20/40 수익 최적화나 운영 적용 금지.
