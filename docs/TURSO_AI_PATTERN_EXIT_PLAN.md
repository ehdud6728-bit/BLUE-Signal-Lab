# Turso AI 패턴·익절·손절 연구 계획

> 2026-11-20 KST. 운영 추천/매매 기능이 아닌 감사 데이터 기반 단계별 구현 계획.

## 사용자 목표

- 예전 AI 시황의 단순 기술 신호 나열을 주 기능으로 삼지 않는다. 앱의 Turso 모드 탭은 **AI 패턴**이며, 최근 강한 패턴·관찰 후보·익절/손절/시간 청산 조건을 핵심으로 한다.
- 코스피/코스닥 지수·시장 폭·업종 강도·거래대금은 후보 패턴의 **시장 국면 보조 증거**다. 미수집 지수나 업종을 추정값으로 채우지 않는다.
- 단순 `D+5/10/20` 수익률은 보조 통계. 주력은 진입 후 실제 도달 순서·익절까지 시간·손절 및 손실폭·분할/추적/시간 청산의 대조 실험이다.

## 현재와 데이터 부족

- `blue_eod_ingest_audit_v1`은 검증된 전 종목 하루 일봉의 감사 원장, `blue_research_signal_audit_v1`은 그날 발견한 패턴 일치 종목 및 R1.1 과거 사례 통계의 원장이다. **매일 한 날짜 저장 ≠ 과거 1~2년 전체 거래일 확보**.
- 기존 R1.1 통계는 외부 marcap 가격 이력과 `asof` 이전 사례로 계산할 수 있지만, Turso가 연속 거래일·패턴 출현 시계열·시장지수·업종·기업행동 조정 후 가격을 보유한다는 보장은 아니다.
- `/api/research/coverage`는 Turso의 **원장 건수만** 읽고 D1/KIS/Gemini/외부 API를 호출하지 않는다. 140일 EOD와 120일 패턴 자료는 *검토 시작 최소 게이트*일 뿐 충분성 확정이 아니다. 실제 행수·누락 거래일·표본 수·완성된 후속 성과 검증이 더 필요하다.
- 과거 1~2년 확정 일봉의 백필은 **별도 사용자 승인·용량/요청량 확인·작은 날짜 범위 dry-run→apply**로 진행. 출처/해시/기존 자료 불일치 시 중단하고 덮어쓰지 않는다.

## 출구 전략 검증 모델 (첫 단계 순수 코드)

`scripts/exit_policy_research.py`는 외부 연결·DB 쓰기·주문 기능이 없는 단일 매매 사례의 시뮬레이터이다.

1. 신호일 종가가 **확정된 이후**에야 신호를 안다는 전제. 가정 진입은 **다음 거래일 시가**. 신호일 종가를 진입가로 사용하여 미래 정보의 혜택을 누리지 않는다.
2. 사전에 명시한 익절선, 손절선, 최대 보유 거래일 중 **첫 도달**로 청산. 일봉의 고가·저가가 같은 날 모두 도달하면 체결 순서를 알 수 없으므로 **손절 먼저**로 보수적으로 분류하고 모호한 사례 수를 별도 표시.
3. 장 시작 전 손절선 아래로 갭이 발생하면 손절선 가격이 아닌 **불리한 시가**로 가정. 목표가 위 갭은 목표가 수준으로만 계산하여 유리한 가격을 꾸미지 않는다.
4. 최대 보유기간을 채우지 못한 현재 진행 사례는 **PENDING**. 1/3/5/10/20거래일 비교에서 미성숙 결과를 임의의 성공/실패로 합치지 않는다.
5. 비용/슬리피지·기업행동/수정주가·일봉 연속성·장중 체결 불명확성을 분리 검증한다. `observed_bar_mfe/mae`는 바 전체 고저가 관측치일 뿐 실제 청산 전 순서와 다를 수 있다.
6. 표본 1~11건은 `SMALL_SAMPLE` 탐색 관찰로만 분류하며, 확률 예측이나 추천으로 승격하지 않는다. 거래일 중첩·여러 파라미터의 후행 선택을 경계하고, 훈련구간과 미래 분리 구간에서 별도 재검증한다.

## 다음 구현 순서

1. **데이터 충족/누락 증명:** EOD·패턴·전 종목 지표의 정확한 날짜 범위와 행 수, 주식 코드·기업행동, OHLCV 연속 거래일. 시장지수/업종 분류의 별도 검증 출처 확정.
2. **안전 백필:** 1~2년을 한 번에 쓰지 않고 작은 날짜 범위별 KRX 감사·재실행 안전성·용량 확인, D1 미사용. 필요 데이터 표본 수 충족 여부 검증.
3. **패턴 출현·결과 이벤트 자료:** 종목·발생일·그날까지의 지표·시장 국면과 후속 일봉 경로를 연결. 각 결과는 발생일의 미래에 해당하는 기간이 끝났을 때만 성숙 표본으로 기록.
4. **최근 효과 검증:** 최근 20·60·120거래일 패턴 성과 및 국면별 첫 익절/손절/시간 청산 통계. 고정·ATR·지지/매물대·추적/분할 규칙을 사전 고정하고 기간 분리 검증.
5. **설명형 AI 후보 카드:** 검증된 수치·출처·날짜만 모델 입력에 제공. 후보/익절/손절/무효화/시나리오/반례/표본·불확실성을 표시. Gemini 호출 비용·서버 한도·캐시를 별도 설계. AI가 임의 가격·확률을 생성할 수 없음. 자동 주문은 개발 범위 밖.
