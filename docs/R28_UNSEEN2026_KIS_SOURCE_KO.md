# R28: Stock-Hunter 신규 종목 × 2026 기간 KIS 원본 수집

## 목적

Stock-Hunter R19~R27은 2020~2025년 동일한 26종목 일봉 37,736행에 반복 적용한 연구입니다. R27의 D+3 종가 확인 규칙은 과거 검토 44건에서 -15% 이하 손실 5→1건, +30% 실제 순수익 7→6건을 기록했으나 새로운 표본의 결과가 아닙니다. BLUE에는 기존 암호화 캐시 KIS 토큰으로 읽기 전용 일봉을 조회해 원본/응답 SHA256을 기록하는 경로가 있습니다. R28은 **새 데이터 소스 확보만** 수행하고 전략 검증은 하지 않습니다.

## 고정 범위

- 신규 30종목: 005930, 000660, 035420, 035720, 051910, 028260, 005380, 000270, 012330, 105560, 055550, 086790, 003550, 015760, 034020, 009150, 006800, 010130, 017670, 033780, 000100, 078930, 096770, 032830, 047810, 207940, 066570, 003490, 011200, 086280
- 기존 R19 26종목과 교집합: 0 (코드의 자동 테스트로 불변 확인)
- 수집: KIS FHKST03010100, 무수정 일봉 GET, 2025-01-02~2026-11-20. 2025년은 55봉 이전 고점 계산을 위한 준비 구간; 평가 기준일은 2026년부터이며 D+60 완결 사건만 검증합니다.
- 기존 R19 가격 CSV의 고정 SHA256: e5edabf1b111d424a0afa8503111d7dd4d6e4827036aa7eea512ef067d122dbc
- 이 30종목은 미리 고정한 유동성이 높은 편의 표본으로 **무작위 전체시장 대표 표본이 아닙니다.** 2026년은 새로 평가하는 과거 기간이지만 실제 미래에 수집되는 prospective OOS는 아닙니다.

## 안전 및 품질 조건

- PR 자동 테스트·dry_run은 KIS API, Turso, 토큰, 주문에 접근하지 않습니다.
- workflow_dispatch / main / mode=token_check는 이미 저장된 토큰을 읽기만 합니다.
- mode=capture는 confirm_fixed_unseen_scope=true가 필수. 30종목×최대8개 페이지(240 GET) 외의 호출을 금지합니다. KIS 토큰 새 발급, D1/Turso 쓰기, 운영 검색·매매 수정, 주문, 로그에 비밀 출력은 모두 금지합니다.
- 티커당 유효 일봉 최소 350개, 데이터 시작일 2025년 초, 종료일 2026년 11월 초, 가격 양수/정렬/중복/거래량·대금 검증, KIS 페이지별 SHA256을 기록합니다.
- 원시 전일 종가 대비 다음 시가 갭 35% 초과는 원인이 인증되기 전 해당 티커 전체 격리. 누락·격리 종목을 다른 성공 종목으로 바꾸지 않습니다. 유효 종목 20개 미만이면 실패 상태를 기록하고 가격 CSV는 생성하지 않습니다.
- 성공 아티팩트에는 원시 OHLCV CSV, CSV SHA256, 종목별 유효기간·조회 원본 페이지 해시·격리/거부 사유를 넣습니다. **원본 확보 성공은 실전 전략 검증 성공이 아닙니다.**
- 상장폐지·거래정지·기업행위 조정·점시점 종목 구성·체결성·호가 슬리피지는 미인증 상태로 기록합니다.

## 실행

1. PR 자동 테스트가 통과하면 PR을 병합합니다.
2. GitHub Actions의 BLUE R28 Frozen 30 New Tickers 2026 KIS OHLCV Source (RESEARCH ONLY) → Run workflow → main → mode=token_check 로 기존 토큰 확인(선택).
