# 실제 키움 굵은 파란 점선 30·2·26 숫자값 대조 도구

## 현재 상태
- [PR #103 병합 후 연구 #45142269176](https://github.com/ehdud6728-bit/BLUE-Signal-Lab/actions/runs/45142269176)은 HLC3 하단 가설로 4건을 재분류했지만 **키움 굵은 파란 점선의 날짜별 실측 숫자 자료는 현재 0건**이다.
- 새 입력 파일 `research/kiwoom_blue_dot_30_2_26_observations.json`의 `observations: []`는 실제로 비어 있다. 사용자 제공 자료가 없는데 임의로 키움 숫자를 만든 일이 없다.
- 기존 `kiwoom_30_2_26_audit.json`에 4개 종목×4개 수식가설의 **날짜별 6개 점선 계산값**을 넣고, 후속 `scripts/blue_dot_30_2_26_observed_line_match.py`가 실제 키움 수치를 해당 날짜에 맞춰 비교한다.

## 키움에서 확인해야 할 정보
**가장 우선: 2026-11-12 하이브(352820) 및 캐스텍코리아(071850)**.
선택일: 2026-11-05, 06, 09, 10, 11, 12 (연속 6거래일). 최소 한 날짜라도 기록하면 오차를 보여주지만, 5회 연속 하락 기울기 확인에는 6개 날짜의 선값이 필요하다.
30·2·26 지표의 **굵은 파란 점선** 수치. 당일 종가나 볼린저밴드 상단/하단 일반값을 대신 입력하지 않는다.
차트 가격구분 KRX/NXT/미확인 및 수정주가 사용 여부도 함께 남긴다. 입력값이 소수 둘째 자리이면 `display_decimals: 2`, 정수까지이면 `0`.

예시 형식(다음 숫자는 **샘플 구조 설명용 가상값이며 실제 선값이 아님**):

```json
{"code":"352820","date":"2026-11-12","line_value_krw":100.00,"display_decimals":2,"source":"USER_REPORTED_KIWOOM_INDICATOR","market_session":"KRX","adjusted_prices":true}
```

## 판정 기준
- HLC3 하단, Close 하단, HLC3 상단, Close 상단 각각에서 해당 날짜 **표시된 자릿수의 반 단위 오차 이내**인지 계산한다.
- 6일이 전부 관측되면 **실제 관찰한 선의 3회/5회 하락 여부**를 별도 판정한다.
- 신호일 화면 시가<실제 점선<종가 여부를 보조로 보여주되 **전일 종가와 전일 실제 선 숫자가 없으면 전체 양봉 돌파 신호 인증은 보류**한다.
- 숫자 오차가 가깝다는 사실만으로 HTS 공식 수식과 수정주가 처리·KRX/NXT 봉·실제 주문체결 검증까지 완료했다고 선언하지 않는다. 운영 AI 검색·추천·매매 변경 없음.
