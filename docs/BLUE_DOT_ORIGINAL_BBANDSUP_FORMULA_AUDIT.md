# 원본 키움 BBandsUp(30,2) + SHIFT(26) 파란점선: 수식 우선 비교

## 이미 사용자에게서 받은 기준
- 차트 대상은 **붉은색 실선과 겹친 굵은 파란색 점선**. 주 설정값 `30,2,26`.
- 사용자가 전달한 키움 원문 수식 중 파란색 `수식2`: `SHIFT(BBandsUp(설정값, 설정값2), 설정값3)`; 값 대입 시 `SHIFT(BBandsUp(30,2),26)`.
- `BBandsUp`라는 함수명은 소스 코드 내 HLC3/종가 및 ±2σ 수치 가설 중 어떤 의미인지 **증거 없이 상단·하단이라고 확정하지 않는다**. 다른 상단 실선과의 시각적 오인도 금지.

## 두 종류의 실제 제공 숫자(독립 검증된 수치가 아님)
- **스페코(013810), 30·2·26:** 2026-10-21 = 1,529.14, 10-22 = 1,531.15, 10-23 = 1,533.75원. 기존 사용자 제공 HTS 지표값으로 기록된 3일 앵커.
- **롯데칠성(005300), 35·2·26 비교:** 2026-11-11 = 100,542, 11-12 = 100,267원. `research/blue_dot_broker_samples.json`의 사용자 제공 별도 35 설정 사례이며, **30일 연구 표본으로 절대 섞지 않는다**.
- 4개 차트(아진산업·캐스텍코리아·에스엘·하이브)에는 굵은 파란 점선 자체의 선택일 정확한 가격값이 아직 없으므로 별도 일치 인증에 사용하지 않는다.

## 새 보고서
- `scripts/blue_dot_original_formula_audit.py`: 이 두 사용자 숫자 집합을 고정 SHA 공개 **비수정** MARCAP 2025/2026에서 해당 날짜가 정상 연속 시장일인 경우에만 계산.
- 30 또는 35 주기와 shift 26에 대해 **HLC3 하단 / 종가 하단 / HLC3 상단 / 종가 상단** 네 모델을 나란히 계산하고, 일별 가격 차이·지표 표시 자릿수 기준 일치 건수·최대/평균 절대 오차를 제공.
- 값이 가까운 모델을 찾더라도 원 함수의 내부 가격기준·볼린저 구현법·수정주가 처리·실제 차트 노출·체결까지 입증했다고 주장할 수 없다. 특히 스페코 3일과 롯데칠성 2일은 주기가 다르고 표본도 적다.
- 기존 `research/kiwoom_blue_dot_30_2_26_observations.json`은 **신규 HTS 숫자 0건**으로 보존하며, 원본 수식과 이전 제공 지표 숫자는 별도 과거 앵커 비교로 분리한다.
