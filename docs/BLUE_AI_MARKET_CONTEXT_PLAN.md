# BLUE AI 시장상황·대응·전망 체크포인트 — 입력 계약 초안

> 상태: **설계만 완료**. 공식 시계열 수집·시장 전제 검증·AI 런타임 제공·매매 자동화 모두 미구현. 기존 Gemini 요약/패턴 검색과 이 문서는 연결되지 않는다.

## 사용자 요구와 판단 한계

- 종목의 기술 신호뿐 아니라 **시장 전반이 바닥을 다지는 중인지**, 급락 위험이 해소되는지, 외국인 수급이 실제 돌아서는지 함께 본다.
- 시장 상황 요약 뒤에 **상승 재개 / 횡보·바닥 확인 / 재하락**의 조건부 전망, 상황별 **대응 방법과 무효화 조건**을 함께 제시한다. 예측이 확정됐다고 말하거나 관측되지 않은 확률·가격·수익을 생성하지 않는다.
- 현재 파란점선 연구에 쓰는 `market_breadth`는 MARCAP 전시장 종목 상승·하락 폭으로 만든 **과거 신호일 종가 시점의 대용 지표**다. 공식 KOSPI/KOSDAQ, VIX 지수, VIX 선물 곡선, 외국인 순매수 집계가 아니다. **15:20 종가 단일가 주문 당시 알 수 있었던 값도 아니다.**
- 'VIX가 40까지 급등', '12월 9일 회사 실적', '엔비디아 CES 발표'와 같은 메시지는 사용자 제공 **확인 전 주장**으로 취급한다. 날짜·발표 여부·수치·조사 출처를 공식 자료에서 확인하기 전 시장 사실로 쓰지 않는다.

| VIX 선물 구조 | 근월물 F1, 차월물 F2, 만기, F2-F1 부호·백워데이션/콘탱고 | Cboe Futures Exchange 공식 시세/명세 | 합법적 역사/실시간 접근 API·사용권 확보 전 수치 미표시 |
| KOSPI·KOSDAQ | 공식 종가 지수와 폭·거래대금 | KRX 및 거래소 공시 | 정규장·통합시세 경계, 시점, 사용권 확인 |

## 데이터 계약(예시 형태)

각 체크포인트에 다음 정보를 **모두** 저장·표시한다. `asof`는 반드시 원천에서 측정한 기준 시각이고, `fetched_at`과 별도다.

```json
{
  "metric": "vix_futures_f2_minus_f1",
  "value": null,
  "unit": "index_points",
  "asof_utc": null,
  "fetched_at_utc": null,
  "timezone": "America/New_York",
  "source_name": "Cboe Futures Exchange",
  "source_url": null,
  "source_vintage": null,
  "data_status": "MISSING",
  "fact_or_inference": "FACT",
  "official_or_proxy": "OFFICIAL_PENDING_ACCESS",
  "regular_or_extended_session": "NOT_APPLICABLE",
  "license_approved": false,
  "notes": "실제 시세와 사용권 확인 전 방향성 판정 금지"
}
```

허용 데이터 상태: `VERIFIED`, `DELAYED`, `MISSING`, `RUMOR`.

- `VERIFIED`: 기준 시각/원천 URL/공식 공개 사실/수치와 사용 권한을 확인한 경우만 사용.
- `DELAYED`: 공식 원천이나 사용 허락된 데이터라도 시장 의사결정 시점에 뒤늦게 들어온 경우. 지연 시간을 명시한다.
- `MISSING`: 숫자·확인 경로가 없거나 출처에 연결하지 못한 경우. `value=null`, **미확인**으로 표기.
- `RUMOR`: 소문 또는 향후 관측 제안. 수치·기업행동·발표 사실로 승격하지 않으며 AI에 사실 단정 금지.
- `fact_or_inference=INFERENCE`는 출처의 원자료와 계산 근거를 같이 명시. 시장 시나리오 결론은 관측 사실이 아닌 조건부 추론으로 별도 표기.

## 화면/문장 출력 계약

1. **관측 사실:** 사용자 선택 기준시각(KST 표시)까지 확정된 원천 수치만 요약. 시점·출처·정규장/시간외 구분을 붙인다. 수집 공백은 `미확인`이라고 쓴다.
2. **시나리오(확률 없음):** (a) 하락 진정·반등 시도, (b) 횡보·재시험, (c) 재하락 세 경로를 **조건부**로 설명하고, 각 경로마다 *확인해야 할 후속 관측 / 반대 증거 / 위험 대응 옵션*을 제시한다.
3. **종목과 결합:** 파란점선 20/30/40×A/B, 상단 매물대 거리·강도, 1/5일 대용 시장폭, 최초 손절 갭·큰 손실을 독립 항목으로 보여준다. **모델 신호를 키움 실제 매수 신호로 주장하지 않는다.**
4. **위험 알림:** 정확한 값 없는 이벤트 예정일, 외국인 매수 전환, VIX 선물 구조 정상화는 모두 '확인 필요'다. 조건부 손절 회피가 동시에 첫 익절 기회를 없앨 수 있음을 **건수와 손익 규모를 따로** 보여준다.
5. **행동 제안의 한계:** 관찰 강화/포지션 크기 축소 검토/추가 확인 대기 등 **선택지**를 설명하되 자동 주문·매수/매도 확정 지시·실시간 추천 배지/골드 승격은 하지 않는다.

## 구현 단계 및 검증 관문

1. **현재 PR:** 오프라인 연구 보고서에 신호일 종가의 시장폭×매물대×손익 원장 및 이 계약 문서만 추가. 운영 AI 연결, Worker·API·DB·UI·주문 변경 없음.
2. **추후 별도 승인:** 데이터 라이선스/공표시각/수정 이력과 원천 감사 SHA 확인. 누락 시 AI가 비어있는 필드를 추정하거나 최신값처럼 쓰지 못하도록 검증.
3. **별도 후속 PR 및 검증:** 데이터와 근거를 가진 결정론적 시장 스냅샷을 생성하고 테스트. 그 뒤에야 AI 프롬프트에 근거·미확인·시나리오를 전달. 이벤트 전후 시계열과 출처 검증, 과거 기준시각 회귀시험과 사용자 검토를 통과해야 런타임 공개 검토.

**금지:** 검증 전 수치를 사실로 생성, 이미 지난 일을 미래에 안 것처럼 보고, 결측을 0으로 대치, 중복 모델 사건의 합계를 실계좌 수익으로 표기, 미래 VIX/외국인 매매 데이터를 과거 신호 필터에 사용, 독립 OOS 없는 '최적' 검색·추천 채택.
