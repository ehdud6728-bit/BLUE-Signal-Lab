## 병행 개발 정책
로드맵은 고정 순서가 아닌 누락 방지 목록이다. 추천 갱신/이력/검색 표시, 최단기 변화 연구, 순환매 데이터 기반, 과거 데이터 확보를 독립적으로 병행한다. 공통 데이터와 검증 의존성은 먼저 해결하고, 운영 반영은 테스트 및 실제 결과 확인 후 진행한다.
