# BLUE Signal Lab — 통합 개발 관리표 (2026-11-27)

최단기 시장 적응형 AI 주식 검색·분석 시스템. 기존 [적응형 연구 로드맵 및 개발 이력](BLUE_ADAPTIVE_ROADMAP.md)을 보존하며, 이 문서는 향후 작업 순서와 완료 조건을 관리하는 통합 기준이다. 2026-11-27 대화에서 재대조한 4장의 기존 계획 및 스마트 장바구니 합의 반영. 아래 상태는 기준일 현재 확인 범위이며 향후 실제 증거에 맞춰 갱신한다. 구현, CI, 실제 데이터 검증, 독립 검증, 운영 화면 검증을 별도로 기록한다.

## 운영 합의 및 연구 중단 경계

- 장바구니 최대 50개 고유 종목; 그 안에서 정밀 추적 책갈피 초기 10개, 실측 통과 후 최대 20개. 기본 120분 분석, 정밀 30분 분석. 전체 현재가 5분 갱신은 목표이며 실제 KIS 및 저장 성능 검증 선행. 장기관찰 기존 분류 유지; 중복 발견일은 동일 종목 데이터 공유하되 사건 이력 별도 유지. 기존 50개 초과 자료 자동 삭제 금지, 신규 등록 제한 및 정리 안내. 정밀 해제 시 기본 추적 복귀. 한도는 서버에서 원자적으로 적용.
- 전체 시장 일봉 패턴 연구는 장바구니 한도와 무관하게 지속. 장바구니 삭제/추적 종료가 연구 이력 삭제를 의미하지 않음. 분봉 선택 표본과 전체 시장 표본은 별도.
- 과거 데이터 누락 확보 및 6개월~2년 기존 목표는 유지하되 단계별 검증, 저장 비용·속도 검토. 10년 확대는 명시적 재승인 전 중단 유지.
- 이전 보류 브랜치 research/same-pattern-advantage-risk 및 폐기 전략 재개 금지. 현재 승인된 ENV20 성공·실패 특성 연구의 범위 내 진행; 다른 패턴 확대는 유효한 기존 연구의 범위 및 사용자 결정 확인 후. 파란점선 등 이전 연구 결과 및 보류 결정 보존, 신규 실험은 승인 범위 확인.
- 과최적화 방지: 새 조건은 가설 사전 고정, 대조군, 실제 성공/실패 차트, 충분한 표본·종목·날짜, 독립 시간순 전진 검증. 기존 데이터 반복 실험은 독립 검증 아님. 조건 확률 및 위험은 검증 표본에서 산출; 임의 점수나 가상 확률 금지.
- HIGH 도달 기회와 종료 종가 수익률 및 비용 포함 실현전략 성과 분리. 상승·하락 순서 일봉 내 불명확 표시; 확인 불가를 0으로 대체 금지. 시장·업종·종목 데이터 기준일 통일, 확정/잠정 구분, 미래 참조·생존편향·기업행동 점검.
- 기본 주기와 종목 수는 운영 상한/목표이지 성능 실측값 아님. 기존 기능 안정성 우선, 관련 변경 묶어 PR/배포 최소화. 각 PR마다 이 문서의 상태와 근거 갱신. 실제 배포·화면 검증 없이 완료 선언 금지.
