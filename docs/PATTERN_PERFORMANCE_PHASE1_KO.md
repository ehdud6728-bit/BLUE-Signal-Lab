# BLUE STOCK APP — 기술패턴 성과 분석 1단계 (연구 전용)

목표: 이미 검색된 종목의 신호 기록을 **패턴별·3/5/10/20거래일별**로 집계하는 최소 분석 엔진. 운영 앱과 데이터베이스는 변경하지 않습니다.

## 실행

```bash
python3 research/pattern_performance_phase1.py --input research/pattern_signals_sample.csv --output /tmp/pattern_performance.json
```

입력 CSV 필수 열: `code,signal_date,pattern,close,forward_3d,forward_5d,forward_10d,forward_20d`. 미래 종가는 **신호 발생 후 정확히 N거래일 뒤의 종가**입니다. 미래 데이터가 없는 날짜는 빈칸으로 둡니다. 동일 종목·날짜·패턴 중복은 오류 처리합니다.

실제 검색 결과의 신호일 당시 패턴 기록을 입력해야 합니다. 예시 파일은 형식 확인용 가상 데이터이며 실전 통계에 사용하면 안 됩니다. 현재 스크립트는 CSV를 수동으로 공급받습니다. 검색 로그 자동 추출·기존 UI 연동·캔들/거래대금 특징 추출은 다음 단계입니다.

승률은 **N거래일 후 종가가 신호일 종가보다 높은 비율**이며, 매매 승률이나 손절/익절 체결 확률이 아닙니다. 신호일 종가 체결, 수수료, 슬리피지, 미래 정보 누출, 표본 중복 및 시장 국면 검증을 별도로 해야 합니다. 표본이 적어도 수치는 보여주되 운영 추천 등급은 부여하지 않습니다.

다음 단계: 검색 로그와 가격 DB의 실제 컬럼 구조 확인 → 미래정보 없는 신호 스냅샷 생성 → 중복/표본 신뢰도/기간별 분리 → 캔들 특징 및 복합 조건 → UI 카드 연결. 파란 점선 수식 검증은 독립 연구로 유지합니다.
